**SimpleEnderButt** is a fun lobby plugin that gives players an EnderButt item that, when used, launches them into the air. Fully configurable and perfect for lobby servers.

## Features

- Customizable item name and lore
- Assignable inventory slot
- Configurable power levels
- Inventory move prevention (if activated)
- Sound feedback when the item is used

## Upcoming features:

- Customizable cooldown
- The option to launch yourself using a command
- The option to ride the EnderButt instead of it just launching you

If you have a feature idea, please open a GitHub issue [here](https://github.com/VulpineFriend87/SimpleEnderButt/issues) and suggest the new feature, I will be happy to implement it in the next version!
